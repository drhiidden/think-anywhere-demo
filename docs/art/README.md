# Art layer — Think Anywhere Demo

Companion for **entropy-triggered dynamic reasoning** in LLMs (see root README and [arXiv:2603.29957](https://arxiv.org/abs/2603.29957)).

## Thesis

*The model speaks its deliberation only when uncertainty rises.*

## MVP piece (planned)

**Entropy Pause Loop (~60 s):**

- Horizontal “token stream” band
- Visual blur/opacity ∝ entropy **H** (simulated from demo run export)
- Red pulse when **H > τ** (τ ≈ 0.7 in project docs) → `<THINK>` beat
